# Компоновка Minerva

Референсы: предоставленный скриншот Codex (постоянная колонка разделов),
`C:\OE\trunk\ai-chat\src\widgets\chat-sidebar` (сменяемые панели и resize),
текущие цвета, типографика и компоненты Minerva.

1. Вынести оболочку из содержимого чата: rail, контекстный sidebar, header, content.
2. Разместить Чаты и Плагины сверху rail, Настройки и сворачивание снизу.
   Чаты сохраняют workspace и сессии; настройки становятся отдельной страницей.
3. Добавить workspace-слоты разделов (rail/sidebar/body), дополнений rail,
   шапки/подвала sidebar, действий header, зон до/после content.
   Сохранять существующие settings/navigation/conversation/composer слоты.
4. Использовать shadcn Resizable для мыши и клавиатуры, ограничений и сброса ширины,
   сохранение ширины и collapsed локально. На узком экране sidebar — overlay.
5. Проверить переходы, отключение активного plugin-раздела, сохранение чата,
   resize мышью и клавиатурой, reload, узкий экран. Сборка и существующие тесты.

Визуальное решение: rail 56px, sidebar 272px (192–480), тёплые тёмные
поверхности Minerva, существующий акцент только для active/focus.
Компоненты: shadcn Sidebar, Resizable, Sheet, Tooltip в текущем radix-mira.
Backend и формат истории не меняются. Скругление верхних углов панелей — 14px.
