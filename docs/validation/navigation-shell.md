## Визуальная проверка

Проверены 1280×800, 900×800, 700×800, 900×550 и 390×844.
Исходная точка: предоставленные скриншоты и `C:\OE\trunk\ai-chat`.
Сохранены поверхности, типографика, бренд и акцент Minerva. Основная область
остаётся отделена от навигации; формы настроек используют доступную ширину.

Во время проверки исправлены: несовпадение позиции иконки настроек,
старый минимум body 700px, перекрывавший mobile-правила в production CSS,
возврат на страницу после выбора пункта мобильного sidebar, несовместимые
с Tailwind 3 варианты в добавленных из registry компонентах.

Screenshots находятся в `agent-artifacts/playwright/` (не входят в Git).
Нативное окно Minerva Harness проверено через Computer Use: существующая
история открылась, rail, sidebar и отдельная страница настроек отобразились.
Снимки браузерных тестов используют fixture-данные; runtime-тесты — временные
каталоги, локальный Rust Host и тестовый провайдер.

Новая оболочка не меняет backend, формат истории, авторизацию и протокол моделей.
Полная работа с внешними платными моделями повторно не проверялась.
