# Проверка локального learning-контура

Дата: 2026-11-10. По согласованию с пользователем Linux Docker/runsc runner оставлен отдельным этапом. Текущее поведение и контракты описаны в [руководстве](../harness-learning.md).

## Объём

Семь необязательных плагинов подключены к локальному runtime, существующему `plugins.call` и панели управления: история, навыки, память, опыт, эксперименты, improvement и curation. Проверены изоляция областей, выключение плагинов, сохранение состояния, блокировка второго владельца хранилища, замороженный контекст дочерних прогонов, бюджеты, отмена и восстановление. История содержит только подтверждённые связи fork; старые связи не угадываются.

Локальный цикл изменяет только текстовые компоненты. Дочерние прогоны не получают инструменты. Исполняемые скрипты, middleware и внешние engines этим адаптером не запускаются. Опыт без объективного доказательства остаётся provisional.

Полный workspace Clippy не является зелёной проверкой: ранее существовавшие ошибки найдены в `mh-workspaces` (`items_after_test_module`, `field_reassign_with_default`), `mh-providers` (`items_after_test_module`) и `mh-lsp` (`too_many_arguments`, `items_after_test_module`). Их наличие сверено с HEAD; посторонний код не менялся ради этой проверки. `ts-rs` также сообщает о неподдержанном разборе `deny_unknown_fields`; это предупреждение генератора, проверка актуальности контрактов проходит.

Логи находятся в игнорируемом `agent-artifacts/`: `learning-workspace-tests.log`, `learning-js-tests.log`, `learning-clippy.log`, `learning-e2e-final.log`.

Последняя правка сохраняет прежний лимит Anthropic и ограничивает новые прогоны без инструментов, не вводя общий token cap для обычных чатов с инструментами. После неё выполнены целевые проверки провайдера/runtime и два серверных E2E; полный набор из 37 сценариев прошёл непосредственно перед ней. Дополнительные логи: `learning-final-provider-tests.log`, `learning-final-build.log`, `learning-final-regression.log`.

## Визуальная проверка

Панель «Плагины → Память» открыта в Chrome через Playwright с реальным Rust HTTP-сервером и временным хранилищем. Просмотрены снимки 1440×900 и 390×844: `agent-artifacts/learning-ui/desktop.png`, `agent-artifacts/learning-ui/mobile.png`. Список, выбор области, добавление и открытие записи остаются читаемыми; горизонтального переполнения на этих снимках нет.

Исправлены перенос выбора области, переполнение полей на узком экране, размеры кнопок и повтор текста в карточке. Изменения ограничены learning-панелью и её подключением к списку плагинов.

## Границы доказательства

HTTP-интеграция работает с тестовыми native API-провайдерами, отвечающими через локальный mock HTTP-сервер. Проверки не расходуют платные model calls. Они доказывают управление состоянием и связность цикла, но не улучшение качества модели и не независимость суждений двух reviewer-моделей. Настоящие внешние провайдеры и нативное окно Tauri отдельно не проверялись. Docker Linux daemon на машине недоступен; изоляция ОС здесь не заявляется.
