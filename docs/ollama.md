# Ollama

В настройках откройте «Модели» → «Добавить провайдера моделей» и выберите шаблон **Ollama**.

По умолчанию используется `http://localhost:11434/v1`. Запустите Ollama и установите нужные модели, затем нажмите «Получить доступные модели», отметьте модели и сохраните провайдера. Они появятся в выборе модели чата. API-ключ для локальной Ollama не нужен; поле можно использовать для защищённого сервера или прокси.

Адрес должен быть доступен с компьютера, на котором работает сервер Minerva. Если Ollama запущена на другом компьютере, замените `localhost` его адресом, сохранив `/v1`.

Интеграция использует [совместимый API Ollama](https://docs.ollama.com/api/openai-compatibility): `/v1/models` и `/v1/chat/completions`. Поддержка инструментов и изображений зависит от выбранной модели. Загрузка и удаление моделей выполняются в Ollama.
