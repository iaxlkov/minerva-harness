# Вложения сессии

Кнопка «+» слева в композиторе открывает меню с пунктом «Прикрепить файл».
Разрешены любые расширения и MIME-типы, включая файлы без определённого MIME
и пустые файлы. PNG/JPEG/GIF/WebP проходят прежнюю проверку сигнатуры, размеров
и декодирования. Остальные файлы сохраняются без изменения байтов.

Лимиты существующего base64 RPC: 10 МиБ на файл, 8 файлов и 20 МиБ суммарно
на сообщение. Для увеличения лимитов потребуется потоковая загрузка.

`attachments.put/get` используют существующее SQLite-хранилище с привязкой
к сессии. История содержит части `image` или `file` с ID, именем, MIME и размером,
без base64 и локальных путей. После перезагрузки карточка файла позволяет скачать
его оригинал. Скачивание не исполняет HTML/SVG и не встраивает их в документ.

Изображения передаются модели прежним способом. Для остальных файлов проекция
контекста проверяет принадлежность сессии и добавляет текстовый дескриптор с ID.
Содержимое файла не попадает в промпт автоматически. Встроенный плагин инструментов
рабочей папки регистрирует:

- `read_attachment(id, offset?, limit?)`: чтение файла текущей сессии, до 1 КиБ
  за вызов (по умолчанию 1 КиБ). Размер учитывает лимит результата инструмента
  после base64 и JSON-экранирования. Ответ содержит `encoding`, `content`, `nextOffset`
  и `eof`; текст возвращается как UTF-8, бинарные данные и разрезанный UTF-8 — base64.
  Работает и в сессии без выбранной рабочей папки.
- `save_attachment(id, path)`: побайтовое копирование в **новый** файл рабочей папки.
  Не перезаписывает существующие файлы, не допускает выхода из папки. Подчиняется
  политике инструментов: `read-only` запрещает, `ask` требует разрешения на вызов.
  После копирования агент может применить доступные парсеры и инструменты.

Универсального PDF/DOCX/OCR/аудиопарсера здесь нет. Загрузка любого формата означает
сохранение оригинала и доступ к нему, а не поддержку этого формата каждой моделью.
Инструменты файлов доступны в локальном профиле с включёнными workspace tools.

Меню расширяется через [composer.menu](plugin-ui.md#меню-композитора).
Хранение остаётся в существующем ContextService; отдельная система плагинов
для вложений не вводится.

Подход проверен по первичным источникам:
[assistant-ui attachment adapters](https://www.assistant-ui.com/docs/guides/attachments),
[DSH attachment service](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/attachment/attachment/README.md),
[DSH UI slots](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/slots.md).
У DSH файлы доступны по сохранённым путям; Minerva использует ID сессии и
явное копирование в workspace, сохраняя существующие границы доступа.
