# Границы модулей

- `src-tauri/src/sessions.rs`: контракт сообщений, проверка данных, правила сессий и построение сохранённой ветки истории; без зависимости от assistant-ui.
- `session_store.rs`: SQLite, транзакции и миграция v1 → v2. Сообщение и состояние интеграции сохраняются атомарно.
- `conversation.rs`: выполнение хода по истории из базы; выбор API или Codex. Codex продолжается только при совпадении модели и сохранённого родительского ответа.
- `providers.rs`: конфигурация провайдеров, Windows Credential Manager, каталог моделей и вызовы Rig.
- `codex.rs`: взаимодействие с Codex App Server, аккаунт, модели, настройки и диалоги. Codex работает отдельно от Rig.
- `plugins.rs`: жизненный цикл встроенных сервисов Cordis.
- `src/sessionHistory.ts`: преобразование сообщений ядра в assistant-ui и обратно; данные интерфейса находятся в пространстве имён `assistant-ui`.
- `src/main.tsx`: представление сессий и runtime чата. История для модели собирается Rust-сервисом из сохранённой ветки.
- `Settings.tsx`, `CodexSettings.tsx`: настройки провайдеров и Codex через статические клиентские вклады.

Формат SQLite не является сериализованным сообщением Rig. Адаптация к моделям выполняется при запуске хода; полный контракт инструментов и вложений остаётся следующим этапом.
