# MH Message Queue

Системный UI-плагин очереди сообщений. Как UI `mh-workspaces`, собирается веб-приложением и регистрирует компоненты через BrowserPluginHost.

- `ui/index.tsx`: регистрация `composer.queue`, компоненты assistant-ui `ComposerPrimitive.Queue`, `QueueItemPrimitive.Text`, `Steer`, `Remove` и настройки LocalRuntime. `QueueComposerRoot` и `QueueComposerSend` обеспечивают FIFO для Enter и кнопки отправки, в том числе во время обработки очереди.
- `ui/queue.css`: оформление очереди в теме приложения.
- Подключение: `apps/web/src/app/plugins.tsx`; настройки runtime импортируются в `pages/chat/Chat.tsx`.
- Проверка: `tests/e2e/message-queue.spec.mjs` проверяет FIFO, загрузку файла существующим адаптером, удаление, приоритет, остановку и продолжение.

Вложения загружаются существующим attachmentAdapter. Очередь хранится в runtime открытого чата; закрытие чата удаляет ожидающие сообщения. Остановка ответа приостанавливает очередь без удаления сообщений. Следующая отправка продолжает обработку; новое сообщение добавляется в конец. «Следующим» поднимает выбранное сообщение в приоритете, не прерывая текущий ответ. Для задачи, запущенной другим клиентом, ввод пока заблокирован.

Отдельного Rust-сервиса нет: очередь исполняется assistant-ui. Запись `message-queue` в системном roster принадлежит `mh-plugin-manager` и описывает эту возможность клиента.
